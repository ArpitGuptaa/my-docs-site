    Arpit Gupta

    Senior Lead Technical Writer

    Technical Documentation | API & Developer Experience | AI | Business Analysis | Docs-as-Code

    I am a Senior Lead Technical Writer with 11 years of experience creating API, SDK, developer, product, and business process documentation for AI, SaaS, FinTech, mortgage, healthcare, DevOps, IoT, and cloud platforms.

    I work closely with product managers, engineers, architects, QA teams, and business stakeholders to understand requirements, analyze workflows, and turn complex technical concepts into clear, user-focused documentation.

    As a Certified Business Analysis Professional (CBAP), I also apply business analysis practices to requirements analysis, workflow analysis, stakeholder collaboration, and product documentation.

    What I Do

    ### Technical Documentation Create clear and structured documentation for complex products, platforms, and technical workflows. **Focus areas** * Product documentation * Developer documentation * User guides * Technical guides * Release documentation * Knowledge bases
    ### API & Developer Experience Design documentation that helps developers understand, integrate, and use APIs and SDKs effectively. **Focus areas** * REST APIs * API references * SDK documentation * OpenAPI * Integration guides * Developer portals
    ### Business Analysis Apply business analysis practices to understand requirements, workflows, stakeholders, and product needs. **Focus areas** * Requirements analysis * Workflow analysis * Process documentation * Functional documentation * Stakeholder collaboration * Requirement clarification
    ### AI & Documentation Automation Explore practical ways to use AI and automation to improve documentation workflows and content development. **Focus areas** * Generative AI * Agentic AI * RAG concepts * Documentation automation * AI-assisted authoring * Content quality automation
    ### Docs-as-Code Build maintainable documentation workflows using modern development practices. **Focus areas** * Git and GitHub * Markdown * MkDocs * CI/CD * Documentation testing * Automated quality checks
    ### Information Architecture Structure large documentation sets so users can find the right information quickly. **Focus areas** * Content organization * Navigation design * Content models * Taxonomy * Content strategy * Documentation governance

    How I Approach Documentation

    My approach combines technical writing, information architecture, product understanding, and business analysis.

    Understand → Analyze → Structure → Write → Validate → Improve

    I start by understanding the product, users, requirements, and workflows. I then organize the information, develop the documentation, validate it with relevant stakeholders and technical sources, and improve it based on user needs and feedback.

    This approach helps me work effectively with both technical and business stakeholders.
