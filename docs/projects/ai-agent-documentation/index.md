# AI agent documentation suite

This project demonstrates the information architecture for a fictional agent orchestration platform named **AgentFlow**. It is designed as a portfolio example of product and developer documentation, not as documentation for an employer product.

## Documentation model

| Area | Typical content |
| --- | --- |
| Learn | Overview, architecture, agents, workflows, tools, memory, models, and events |
| Build | REST APIs, SDKs, webhooks, event framework, and CLI |
| Deploy | Cloud, container, Kubernetes, scaling, and monitoring guidance |
| Manage | Authentication, users, organizations, roles, and security |
| Reference | API reference, SDK reference, error codes, and limits |

## Primary audiences

- Application developers building agents and integrations
- Platform engineers deploying and operating the service
- Administrators managing authentication and access
- Technical evaluators understanding platform architecture
