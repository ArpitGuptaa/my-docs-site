# Migration validation

## Automated checks

| Check | Purpose |
| --- | --- |
| File count and manifest | Confirm expected files were processed |
| Unsupported-tag report | Identify markup that requires manual handling |
| Link validation | Find broken internal and external references |
| Asset validation | Find missing or incorrectly rewritten images and downloads |
| Markdown linting | Detect malformed source patterns |
| Strict site build | Detect invalid navigation, extensions, and page references |

## Editorial checks

Automation cannot determine whether a converted page is still useful. Review representative pages for task flow, terminology, duplicated content, outdated instructions, heading structure, accessibility, and whether the new navigation matches user needs.

## Completion criteria

A migration is complete when the target site builds cleanly, critical links and assets resolve, required content is present, high-risk templates have been reviewed, and the published experience is usable.
