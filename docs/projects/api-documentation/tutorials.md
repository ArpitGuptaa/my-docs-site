# API tutorial pattern

A tutorial should help a developer complete a meaningful end-to-end task rather than repeat the endpoint reference.

## Recommended structure

1. State what the developer will build or complete.
2. List prerequisites and required permissions.
3. Explain the minimum concepts needed for the task.
4. Provide tested requests in the order they are used.
5. Show expected responses and how to verify success.
6. Explain common failure paths.
7. Link to the relevant reference pages.
8. Provide a next step.
