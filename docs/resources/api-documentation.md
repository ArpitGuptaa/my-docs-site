# API documentation practice

API documentation should help a developer move from understanding the product to completing a working integration.

## Organize the developer journey

| Layer | Developer question |
| --- | --- |
| Overview | What can I build with this API? |
| Get started | How do I make a successful first request? |
| Concepts | How do the resources and lifecycle work? |
| Tutorials | How do I complete an integration task? |
| Reference | What does this endpoint accept and return? |
| Errors | Why did the request fail and what should I do? |
| Webhooks | How does my application receive asynchronous changes? |

## Review API content

Verify authentication, permissions, base URLs, methods, parameters, request bodies, response fields, status codes, error behavior, pagination, version assumptions, webhooks, and cross-references. Test code samples when possible or identify them clearly as illustrative.
