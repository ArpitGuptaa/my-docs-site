<h2 id="developer-documentation">Developer documentation</h2>

I create developer content for REST APIs, SDKs, integrations, authentication, requests and responses, webhooks, error handling, implementation tutorials, and reference material. My workflow includes Postman, OpenAPI and Swagger, JSON examples, and validation against product behavior.

<h2 id="product-documentation">Product documentation</h2>

My product documentation experience includes user guides, administrator guidance, implementation content, deployment guidance, release documentation, troubleshooting, FAQs, technical specifications, and structured knowledge content for enterprise products.

<h2 id="information-architecture">Information architecture</h2>

I organize documentation around user goals and product workflows. This includes navigation design, content hierarchy, reusable structures, terminology, content models, cross-references, documentation portals, knowledge bases, and governance for larger documentation sets.

<h2 id="docs-as-code">Docs-as-code</h2>

I use Git-based authoring and review workflows with Markdown and MkDocs. Documentation engineering work includes pull-request review practices, Vale, CSpell, link validation, strict builds, CI/CD checks, and repeatable publishing workflows.

<h2 id="cloud-and-devops">Cloud and DevOps</h2>

My technical coverage includes SaaS and IaaS concepts, cloud deployment, DevOps, continuous integration and delivery, release automation, microservices, databases, deployment workflows, and operational guidance.

<h2 id="enterprise-ai">Enterprise AI and agent platforms</h2>

My current work includes enterprise AI and AI agent platforms: AI-driven product capabilities, agent workflows, platform concepts, integrations, APIs, implementation requirements, enterprise use cases, and release changes.

<h2 id="content-strategy">Content strategy and quality</h2>

I work on content planning, documentation governance, structured authoring, DITA, UX writing, technical editing, Microsoft-style guidance, active voice, accessibility, editorial review, terminology, and automated quality validation.

<h2 id="requirements-and-workflows">Requirements and workflows</h2>

I collaborate with product managers, engineers, architects, QA teams, DevOps teams, and business stakeholders to clarify requirements, analyze workflows, validate technical behavior, identify documentation needs, and improve documentation processes.
