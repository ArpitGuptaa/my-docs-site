## Documentation principles

<div class="callout"><strong>Write for the task.</strong> I organize content around what users need to understand or complete, then validate terminology, links, examples, and build output before publication.</div>

My working standards include Microsoft-style technical writing, active voice, scannable procedures, descriptive headings, meaningful link text, accessible images, consistent terminology, and automated quality checks where they add value.
